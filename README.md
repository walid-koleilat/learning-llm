# learning-llm

A workspace for learning LLMs in public — from a product manager's perspective.

## What's in here

I use this repo to capture what I'm learning about LLMs: how models actually work under the hood, what evals catch (and don't), and how agentic patterns shift product engineering. Most of it is rough — notebooks and scratch files, not polished tutorials.

**Current state:** mostly placeholder hello-world files. As I work through specific topics, more substantive notebooks land here.

## Why this is public

I write at the intersection of AI and product on [Substack](https://substack.com/@wkoleilat). This repo is the layer below the writing — the rough notes and code experiments that sometimes become posts.

If something here is useful, take it. If you spot something wrong, open an issue.
